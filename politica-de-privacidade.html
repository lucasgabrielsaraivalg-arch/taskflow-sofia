TASKFLOW SOFIA

Política de Privacidade

Última atualização: setembro de 2026

O TaskFlow Sofia é um aplicativo de gestão de tarefas e agenda, de uso privado, desenvolvido e mantido por Lucas Gabriel Saraiva ("desenvolvedor", "nós"), em Rondonópolis — MT. Esta política descreve como o aplicativo trata dados pessoais, em conformidade com a Lei nº 13.709/2018 (Lei Geral de Proteção de Dados — LGPD) e com as políticas de dados dos serviços integrados.

1. Dados que tratamos

  • Dados de conta dos usuários autorizados (nome de usuário e credenciais de acesso ao aplicativo).
  • Dados de uso do aplicativo: tarefas, compromissos, categorias, anexos e registros de atividade inseridos pelos próprios usuários.
  • Dados de agenda do Google, exclusivamente mediante autorização expressa, conforme a seção 2.

2. Integração com o Google Calendar (TaskFlow Sofia)

O TaskFlow Sofia pode, mediante autorização expressa do usuário via OAuth do Google, acessar a agenda Google (Google Calendar) do próprio usuário para criar, atualizar e remover eventos que espelham compromissos e tarefas registrados no sistema, incluindo a geração de links de reunião (Google Meet).

O uso de informações recebidas das APIs do Google observa a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use). Os dados de agenda: (i) são usados exclusivamente para a sincronização solicitada pelo usuário; (ii) não são vendidos, compartilhados com terceiros ou utilizados para publicidade; (iii) não são utilizados para treinamento de modelos de inteligência artificial; e (iv) podem ter o acesso revogado pelo usuário a qualquer momento em myaccount.google.com/permissions.

3. Finalidades e bases legais

Os dados são tratados exclusivamente para o funcionamento do aplicativo (gestão de tarefas e agenda dos usuários autorizados) e, quando aplicável, mediante consentimento do titular — como na autorização da integração de agenda descrita acima.

4. Compartilhamento

Não vendemos dados pessoais nem os compartilhamos com terceiros. Os dados permanecem no servidor privado do aplicativo e nas contas Google dos próprios usuários que autorizarem a integração.

5. Segurança e retenção

Adotamos medidas técnicas para proteger os dados (controle de acesso por login, autenticação e registro de atividades). Os dados são retidos enquanto o aplicativo estiver em uso pelos usuários autorizados e podem ser excluídos a pedido.

6. Direitos do titular

Nos termos da LGPD, você pode solicitar confirmação de tratamento, acesso, correção, anonimização, portabilidade, eliminação e informações sobre compartilhamento, além de revogar consentimentos.

7. Contato

Para exercer seus direitos ou esclarecer dúvidas sobre esta política, entre em contato com o desenvolvedor: lucasgabrielsaraiva.lg@gmail.com — Lucas Gabriel Saraiva, Rondonópolis — MT.
